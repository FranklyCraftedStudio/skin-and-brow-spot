# The Skin and Brow Spot

Static website for The Skin and Brow Spot. The site is served from `index.html` at the repository root.

## Publish with GitHub Pages

The GitHub Actions workflow in `.github/workflows/pages.yml` deploys the site when changes are pushed to `main`, or when run manually from the Actions tab.

To publish:

1. In the repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
2. Ensure the account or organization plan supports GitHub Pages for this private repository. The repository is currently private; do not change its visibility unless you intend to make its source code public.
3. Run the **Deploy website to GitHub Pages** workflow, or merge a change into `main`.

The project site URL will be `https://franklycraftedstudio.github.io/skin-and-brow-spot/` once GitHub Pages is enabled and a deployment succeeds. GitHub Pages can take a few minutes to publish the first deployment.
